Life Dashboard

Privacy Policy

Last updated 24 August 2026

Life Dashboard is a personal project built and used by one person, Alex Babcock. It is not a product, not a service offered to anyone else, and has exactly one user. This page describes what it reads from Google, where that data goes, and how to stop it.

What it is

Life Dashboard is a private web app that assembles a morning brief — the day's classes hour by hour, what is due in the next fortnight, and unread mail grouped by sender. It reads that from the owner's own Google account and displays it on the owner's own phone.

What it reads from Google

Three read-only scopes. Nothing is ever written back to any Google service.

ScopeWhat is actually read
calendar.readonly Events on the primary calendar within a rolling 14-day window: title, start and end time, location, and the dates of all-day entries.
tasks.readonly Open (not completed) tasks: list name, title, notes, and due date.
gmail.readonly Unread inbox messages from the last 14 days, limited to the From, Subject and Date headers. Message bodies and attachments are never requested, received, or stored.

Where the data goes

  • A Cloudflare Worker holds the Google credentials and makes the API calls. Responses pass through it and may be held in an in-memory cache for up to two minutes. Nothing is written to a database, because there is no database.
  • The owner's phone keeps the most recent response in browser storage (localStorage) for up to 14 days, so the app opens instantly and works without a network connection. Clearing the browser's site data erases it.
  • Nowhere else. No analytics, no tracking, no advertising, no error reporting service, no third-party scripts, and no other recipients of any kind.

Google API Services Limited Use

Life Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically: the data is used only to display the owner's own dashboard to the owner, it is never transferred to anyone, it is never sold, it is never used for advertising, and it is never used to train any machine learning or AI model. No human reads it other than the account owner.

Course files

The Courses screen lists coursework kept in a folder on the owner's own computer. Only folder and file names are read — file contents never leave that computer. Those names are compiled into the published site, which is hosted publicly, and the owner is aware of this.

Retention and revoking access

  • Google access can be revoked at any time at myaccount.google.com/permissions. The app stops working immediately when it is.
  • The cached copy on the phone expires after 14 days on its own, and is removed immediately by clearing the browser's site data for this site.
  • There is no account to delete, no sign-up, no mailing list, and no data retained on any server after a request completes.

Children

This is a single-user personal tool and is not directed at children.

Changes

If what the app reads ever changes, this page changes with it, and the date at the top is updated.
